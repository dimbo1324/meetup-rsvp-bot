# Модули правил для AI-ассистентов

Единый источник истины для правил, которым подчиняются все AI-ассистенты (Claude Code,
Codex и любые будущие агенты) в этом репозитории.

## Как это устроено

```text
.ai/universal/*.md   Переносимые правила. Годятся для ЛЮБОГО проекта. Никогда не
                     упоминают имя проекта, пути и детали стека.
.ai/project/*.md     Правила именно ЭТОГО проекта: карта репозитория, команды, доменные
                     ограничения, отслеживание прогресса.
CLAUDE.md            Тонкая точка входа для Claude Code. Подключает все модули нативным
                     синтаксисом @path. Главный ассистент проекта — Claude.
AGENTS.md            Точка входа для Codex и остальных. ГЕНЕРИРУЕТСЯ склейкой тех же
                     модулей. Руками не править.
.ai/CHANGELOG.md     История изменений правил: что, почему и когда.
```

Модули загружаются по порядку имён файлов: сначала `universal/01..NN`, затем `project/10..NN`.
Более поздние перекрывают более ранние: проектные правила главнее универсальных.

## Как редактировать

1. Измените или добавьте модуль в `.ai/universal/` или `.ai/project/`.
2. Запишите изменение в `.ai/CHANGELOG.md`.
3. Перегенерируйте `AGENTS.md`: `uv run python dev.py sync-agents`.
4. Закоммитьте модуль, запись журнала и новый `AGENTS.md` вместе.

Никогда не правьте `AGENTS.md` напрямую: шлюз качества падает, пока он не синхронизирован.
`CLAUDE.md` перегенерации не требует — Claude Code разворачивает `@`-импорты при старте сессии.

Полный протокол изменения правил (когда можно, кто решает, как разрешать конфликты) —
`universal/08-rules-evolution.md`. Прочтите его до правки любого модуля.

## Бюджет размера и уровни модулей

Codex читает не более 32 КиБ инструкций проекта. `sync-agents` падает, если собранный
`AGENTS.md` больше 30 КиБ.

- **inline** (по умолчанию) — модуль целиком вставляется в `AGENTS.md`.
- **extended** — вставляются только заголовок, путь и суть в одну строку. Включается
  пометкой `<!-- tier: extended -->` в первых пяти строках и строкой
  `> **Суть.** Одно предложение о ключевых правилах модуля.` сразу после заголовка.

Inline — то, что агент обязан знать до чтения чего-либо ещё: ориентация, процесс,
ограничения, предотвращающие необратимый вред. Extended — детализация, которую читают,
когда задача её касается, и она обязывает так же, как inline. `CLAUDE.md` подключает все
модули независимо от уровня.

## Как подхватить проект с нуля

Любой ассистент (даже без памяти) читает `CLAUDE.md` / `AGENTS.md` → выполняет ритуал
ориентации из `project/13-progress-tracking.md` → видит следующую веху в `docs/ROADMAP.md`.

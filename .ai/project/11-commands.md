# Команды проекта

> **Суть.** Всё рутинное — через `uv run python dev.py <команда> [--bot <бот>]` (`list` — каталог); перед слиянием обязателен `quality-gate` (с `--bot`, если задача только про одного бота); окружение синхронизировать только `uv sync --all-packages` или `dev.py setup`.

Рутинные задачи выполняются через `dev.py` в корне (только стандартная библиотека,
кроссплатформенно), а не через собранные вручную последовательности. Каталог:
`uv run python dev.py list`. Без `--bot <бот>` проверки идут по всем ботам; команды запуска
требуют `--bot`, когда ботов больше одного.

| Команда | Что делает |
|---|---|
| `doctor` | Окружение: Python 3.14, uv, git, docker (необязателен), `.venv`, pre-commit-хук, `.env` каждого бота |
| `setup [--bot]` | `uv sync --all-packages --all-groups`, `.env` ботов из `.env.example`, шаги `setup` ботов (например, Chromium), pre-commit-хуки |
| `bots` | Список ботов: каталог, пакет, платформа |
| `sync-agents` | Перегенерирует корневой и вложенные `AGENTS.md` из `.ai/`; `--check` только проверяет |
| `check-layout` | Контракт каталога каждого бота и запрет импорта пакета одного бота из другого |
| `format` / `lint` | `ruff` по всему репозиторию (у ботов — наследуемая конфигурация) |
| `typecheck [--bot]` | `mypy`: инструменты корня (strict) и каждый бот по своей конфигурации; тесты не проверяются |
| `test [--bot]` | `pytest` инструментов корня и каждого бота отдельным процессом в каталоге бота; аргументы передаются дальше |
| `quality-gate [--bot]` | Полный шлюз: `sync-agents --check`, паритет зеркал, `check-layout`, lint, typecheck, test. Обязателен перед слиянием |
| `migrate [--bot]` | `alembic upgrade head` для бота с `alembic.ini` |
| `run [--bot]` | Миграции и `python -m <пакет>` бота с его окружением |
| `audit` | `pip-audit` установленных зависимостей (нужен интернет, в шлюз не входит) |

Запуск: `uv run python dev.py <команда>`. Прямые `uv run ruff|mypy|pytest` допустимы, но шлюз
качества запускается только через `dev.py quality-gate`. Задача затронула одного бота —
достаточно `quality-gate --bot <бот>`; затронула корень (`dev.py`, `scripts/`, `pyproject.toml`,
`uv.lock`, правила) — полный шлюз.

## Окружение

- Один `.venv` в корне на все боты. Синхронизировать только `uv sync --all-packages` (или
  `dev.py setup`): `uv sync` без флага или из каталога бота сузит окружение до одного участника.
- Python 3.14 (`.python-version`), менеджер — `uv`; точные версии — `uv.lock` (коммитится).
- Не переходить на Python 3.15: aiogram 3.31 требует `<3.15`.
- `.env` бота создаётся из его `.env.example` и не коммитится.

## Обязанность держать команды актуальными

Если задача изменила способ сборки, проверки или запуска, обновите `dev.py` и эту таблицу в той
же задаче. Новая подсистема, ставшая частью процесса, добавляется в `quality-gate`.

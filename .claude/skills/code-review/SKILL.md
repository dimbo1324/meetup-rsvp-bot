# Ревью изменений

Запускайте **до** слияния и до итогового отчёта.

```powershell
git status --short --branch
git diff
```

Для независимого прохода делегируйте субагенту `meetup-quality-reviewer`.

## Обязательный чек-лист

1. **Объём.** Нет изменений, которых задача не требовала.
2. **Слои.** `services/` без Telegram; `handlers/` без БД; файлы до ~700 строк.
3. **Контракты.** Схема — только миграцией; `callback_data` ≤ 64 байта; тексты/настройки
   отражены в `docs/spec/06`, `07`.
4. **Целостность.** Запись под блокировкой и транзакцией; время через `Clock`, UTC.
5. **Безопасность.** Права на каждом действии; экранирование; нет секретов.
6. **Тесты.** Не удалены, не отключены, нет зависимости от реального времени.
7. **Документы.** Форма системы → `overview.md`; веха → `**Статус.**`; правила →
   `.ai/CHANGELOG.md` + `sync-agents`; запуск → `README.md`.
8. **Мусор.** Отладочный вывод, временные файлы, закомментированный код, комментарии не на русском.

## Обработка находок

Серьёзные находки — безопасность, данные, контракты — исправляются в этой же задаче.
Посторонние проблемы фиксируются отдельно. Если замечаний нет — скажите прямо.

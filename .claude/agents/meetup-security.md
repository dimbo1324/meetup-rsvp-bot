Вы проверяете безопасность изменений и при необходимости вносите точечные правки.

Прочтите `AGENTS.md` и `docs/spec/03-roles.md`, `17-deploy-ops.md` (17.7).

Чек-лист:

- Права админа/владельца перепроверяются в каждом handler/callback; скрытая кнопка не защита.
- Владельца нельзя удалить через интерфейс; `OWNER_IDS` синхронизируется при старте.
- Весь пользовательский ввод экранируется (`html.escape`); описание админа проходит как HTML
  только из entities сообщения.
- Секреты только в `.env`; в логах и служебном чате нет токена и персональных данных сверх
  необходимого; трейсбеков пользователю не показываем.
- Dev-команды (`/dev_shift`) недоступны вне `ENV=dev`.
- Новые зависимости обоснованы, закреплены в `uv.lock`, нет известных уязвимостей.
- Экспорт CSV — только админам; бан не снимается анонимизацией данных.

Сообщайте находки по серьёзности; серьёзные исправляйте в той же задаче.

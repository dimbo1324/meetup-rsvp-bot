# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Изменения правил для
AI-ассистентов записываются отдельно в `.ai/CHANGELOG.md`.

## [Не выпущено]

### Добавлено

- M6.1 (бизнес-логика по ТЗ заказчика): строка «В очереди: N» в посте, шаблон новой встречи по прошлой (`EventService.last_event_template`), признак `dm_available` в списке участников, миграция `0004`.
- Автотесты: бизнес-логика, Telegram-слой, диалоги меню и отметка явки (около 1470 тестов), общая тестовая
  инфраструктура (`tests/helpers.py`, `tests/tg_fake.py`).

### Изменено

- По ТЗ заказчика: запись по умолчанию закрывается в момент начала встречи (раньше за 3 ч), имена в посте скрыты, лист ожидания включён; автосоздание — `auto_create_days_after` («через N дней после встречи») вместо `auto_create_weekday`.

### Исправлено

- Аудит 2026-10-24: автобан снимается при падении неявок ниже порога по любой встрече; неудавшийся пересчёт
  банов дожимает задача `ban_recheck` (миграция `0003`, `events.bans_evaluated_at`); «+1» при выключенной
  настройке — доменная ошибка; тексты уведомлений и напоминаний через единый рендер (без «, .» при пустом
  месте, длины в UTF-16); служебные сообщения с датой и именем; имя пользователя не затирается пустым;
  ручной бан без записи в БД из диалога; команды меню по ролям; подтверждение уменьшения лимита;
  постраничная отметка явки без потери быстрых нажатий; нестабильные id окон aiogram-dialog; лимиты
  подписи и превью; токен — `SecretStr`, понятные коды выхода при неверном `.env` и токене, UTF-8 в консоли
  Windows. Тестов — 1672.

- Правка даты встречи в меню: год вне 2000–2100 отклоняется подсказкой вместо `OverflowError`.

- Меню админа на aiogram-dialog (встречи, мастер, участники, баны, админы, настройки, выбор пользователя)
  и интерфейс отметки явки в личке админа.

- Веха M2: Telegram-слой — обновление постов с debounce, уведомления, обработчики кнопок/inline/`/start`,
  middleware, запуск приложения (`app.py`), миграции при `dev.py run`.

- Бизнес-логика M3–M6 и M9 (без тестов): админы, правка и отмена встреч, участники, CSV, баны, явка,
  лист ожидания, настройки и тексты, планировщик с бэкапом, корень сборки `container.py`;
  миграция `0002` (`bans.auto_removed`, индекс записей по пользователю).

- Веха M1: модели БД и миграция `0001`, расчёт времени встречи, сервисы создания встречи, записи и отмены,
  рендер поста с контролем длины и экранированием.

- Каркас проекта (веха M0): `pyproject.toml` (Python 3.14, uv), `config`, `clock`, `db`, Alembic,
  Dockerfile, compose, CI, pre-commit, `dev.py`.
- Система правил для AI-ассистентов: `.ai/`, `CLAUDE.md`, `AGENTS.md`, `.claude/`, `.codex/`.
- Документация: спецификация разбита на `docs/spec/`, добавлены `docs/ROADMAP.md`,
  `docs/open-questions.md`, `docs/architecture/`.

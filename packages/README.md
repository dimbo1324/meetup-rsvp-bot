# Общие библиотеки

Здесь будут пакеты, общие для нескольких ботов: каждый — `packages/<имя>/` со своим
`pyproject.toml` (участник uv workspace), `src/` и `tests/`. Бот подключает пакет зависимостью
`<имя>` и строкой `<имя> = { workspace = true }` в `[tool.uv.sources]`.

Пакет появляется только когда код реально нужен двум ботам и стабилен; до этого копия дешевле
ранней абстракции. Правило — `.ai/project/12-monorepo.md`, решения — `docs/monorepo.md`.

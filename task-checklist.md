# Чек-лист задачи: registro-civil-bot, быстрый старт под Windows 11

Указание владельца: запуск под Windows 11 через терминал (cmd или PowerShell), без окна и exe;
графика — позже, когда бот заработает. Работа 2 из ночной постановки: отдельная ветка
`feat/rcbot-win11-quickstart`, **в `main` не сливается** — владелец посмотрит и решит.

Обозначения: `+` — сделано, `-` — не сделано или сделано частично.

## Подготовка

- [+] Прочитаны `install.ps1`, `register_task.ps1`, мастер `rcbot init`, тесты скриптов
- [ ] Чек-лист закоммичен до основной работы

## Реализация

- [ ] `rcbot init` спрашивает номер этапа (или адрес шага «Agenda») и номер заявки, проверяет и
      пишет в локальный `.env`, не в репозиторий
- [ ] `scripts/quickstart.ps1`: проверка Windows, `uv` (установка через winget по подтверждению),
      зависимости без инструментов разработки, Chromium только если нет Chrome и Edge, `rcbot init`,
      `rcbot doctor`, предложение включить автозапуск, понятные следующие шаги
- [ ] `scripts/quickstart.cmd` (двойной щелчок без политики выполнения) и `scripts/rcbot.cmd`
      (короткий вызов `rcbot <команда>` без `uv run --all-packages`)
- [ ] Инструкция в `README.md` бота: быстрый старт по шагам, что делает владелец сам

## Оговорки

- Секреты вводятся только в консоли (скрытый ввод) и уходят в Credential Manager; скрипт их не
  видит и не пишет.
- Вход на живой сайт и разведку (`rcbot discover`) делает владелец, скрипт их не запускает.

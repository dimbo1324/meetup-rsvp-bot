# Чек-лист задачи: registro-civil-bot, публичная страница SAE — главный источник (решение R12)

Решение владельца (2026-11-14): главный источник — публичная страница записи SAE
(`sae.mec.gub.uy/sae/agendarReserva/Paso1.xhtml?e=9&a=82`), открывается без входа и без
контрольного вопроса. Причина: bpmgob после каждого входа требует шаг 1 с контрольным вопросом,
который бот по правилам не проходит, поэтому календарь bpmgob боту недоступен.

Бот только читает страницу SAE: никуда не входит, ничего не нажимает, форм не отправляет.
Как выглядит страница с местами, пока неизвестно: в первой версии «места есть» — это пропажа
фразы «no hay cupos disponibles» на странице записи; даты разбираются позже по снимку страницы.

Обозначения: `+` — сделано, `-` — не сделано или сделано частично.

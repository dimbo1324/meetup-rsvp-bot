# Чек-лист задачи: registro-civil-bot, ntfy без ссылки click (решение по Q-M4)

Решение владельца (2026-11-12): убрать поле `click` из push ntfy. Push показывает только даты и общую
фразу, по нажатию открывается приложение ntfy; ссылка на шаг «Agenda» остаётся только в Telegram.
Причина: ссылка содержит номер этапа, а ntfy — сторонний сервис (R1, инвариант 6).

Обозначения: `+` — сделано, `-` — не сделано или сделано частично.

# Чек-лист задачи: registro-civil-bot, выбор браузера (решение R8)

Указание владельца (2026-11-12): бот работает с любым браузером на движке Chromium, первым —
Google Chrome, затем Microsoft Edge, затем встроенный Chromium Playwright. Целевая ОС — Windows 11.
Ветка `feat/rcbot-browser-choice`; слияние в `main` — только после зелёного шлюза и по просьбе
владельца (просьба «делай Chrome и Edge сразу» получена, публикация — по прошлому указанию
«слей в main и запушь»; здесь публикуем после зелёного шлюза и CI).

Обозначения: `+` — сделано, `-` — не сделано или сделано частично.

## Реализация

- [+] Настройка `RCBOT_BROWSER` = `auto` | `chrome` | `msedge` | `chromium` (по умолчанию `auto`)
- [+] `auto`: Chrome → Edge → Chromium Playwright; явный выбор — без запасных вариантов
- [+] `launch` пробует каналы по порядку, в журнал пишет, какой браузер запущен (без путей с именем пользователя)
- [+] `rcbot discover` использует тот же выбор (старая `RCBOT_DISCOVER_CHANNEL` заменена)
- [+] `rcbot doctor` показывает найденные браузеры и тот, что будет использован; код 1, если нет ни одного

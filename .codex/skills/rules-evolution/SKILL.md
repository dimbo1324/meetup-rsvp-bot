# Эволюция правил агентов

Полный протокол — `.ai/universal/08-rules-evolution.md`; здесь — операционный путь.

## Главный предохранитель

**Никогда не ослабляйте правило, чтобы упростить текущую задачу.** Если правило мешает и
кажется неверным: остановитесь, сообщите о конфликте, предложите изменение.

## 1. Нужно ли менять

Обязательно, когда: правило фактически ложно; одно трение стоило времени дважды; ревью
повторно находит один класс дефектов; владелец дал постоянное указание; изменился процесс;
правило оказалось вредным.

## 2. Можно ли самому

**Самостоятельно** — уточнять и исправлять: путь, команда, противоречие, пример, новое
ограничение, которое владелец только что высказал.
**С одобрения владельца** — всё, что ослабляет: удаление правила, смягчение порога/шлюза,
смена определения готовности, политики веток/публикации, языка, документации.

## 3. Примените

```powershell
# 1. Правьте ровно одну тему в .ai/universal/ или .ai/project/
# 2. Запись в .ai/CHANGELOG.md: дата, что, почему, кто решил
uv run python dev.py sync-agents          # 3. перегенерировать AGENTS.md
uv run python dev.py sync-agents --check  # 4. проверить синхронизацию и бюджет
```

Если затронуты `.claude/` и `.codex/` — зеркальная правка в той же задаче. Коммитьте модуль,
запись журнала и `AGENTS.md` **вместе**.

# Ревью изменений

Запускайте **до** слияния и до итогового отчёта.

```powershell
git status --short --branch
git diff
```

Для независимого прохода делегируйте субагенту `quality-reviewer`; для `registro-civil-bot`
дополнительно — `rcbot-privacy`, для `meetup-rsvp-bot` — `meetup-security`, если задеты
права, ввод или данные.

## Обязательный чек-лист

1. **Объём.** Нет изменений, которых задача не требовала; одна задача — один бот (кроме
   общего: корень, `packages/`, правила, CI, `uv.lock`).
2. **Границы.** Бот не импортирует другой бот (`dev.py check-layout`); слои бота по его
   правилам; файлы до ~700 строк.
3. **Контракты.** Схема — только миграцией; форматы, тексты, настройки отражены в
   требованиях бота.
4. **Целостность.** Время через абстракцию часов, UTC в хранилище.
5. **Безопасность.** Права на каждом действии; экранирование; нет секретов и персональных
   данных в коде, тестах, фикстурах, логах.
6. **Тесты.** Не удалены, не отключены, нет зависимости от реального времени и живых сервисов.
7. **Документы.** Форма системы → `overview.md` бота; веха → `**Статус.**`; правила →
   `.ai/CHANGELOG.md` + `sync-agents`; запуск → `README.md` бота.
8. **Мусор.** Отладочный вывод, временные файлы, закомментированный код, комментарии не на русском.

## Обработка находок

Серьёзные находки — безопасность, данные, контракты — исправляются в этой же задаче.
Посторонние проблемы фиксируются отдельно. Если замечаний нет — скажите прямо.

### Аудит и доведение до рабочего состояния

**Статус.** Готово 2026-10-24. Подход: сначала тест-требование, затем правка кода (тесты не
подгонялись под поведение). Поставлено: автобан снимается при падении неявок ниже порога по любой
встрече; пересчёт банов дожимает задача планировщика `ban_recheck` (миграция `0003`,

меню по ролям (`telegram/commands.py`); подтверждение уменьшения лимита; постраничная отметка явки без
потери быстрых нажатий; устранена нестабильность диалогов (id окон aiogram-dialog, `dialogs/intent_ids.py`);
токен — `SecretStr`, понятные коды выхода при неверном `.env` и токене. Архитектурные тесты стерегут слои,
время только из `Clock` и единственность определений. Итог: 1672 теста, 2 пропущены на Windows (права файлов).
Не проверено на реальном Telegram (нужен тестовый бот) — это задача пилота M8.

# 21. Приложения

### Приложение А. Настройка бота в BotFather

Выполняется для боевого бота каждой локации (17.8) и для каждого тестового бота. Пошагово — [README](../../README.md#2-настройка-бота-в-botfather), раздел 2.

| Команда | Значение |
|---|---|
| `/newbot` | Имя и username; BotFather выдаёт токен — значение `BOT_TOKEN` |
| `/setdescription`, `/setabouttext` | «Бот для записи на встречи сообщества» |
| `/setuserpic` | Аватар |
| `/setinline` | Включить, placeholder: «Выберите встречу…» |
| `/setinlinefeedback` | **Enabled** (обязательно, см. 8.1): без него бот не узнает `inline_message_id` разосланных постов |
| `/setjoingroups` | Enable: бот нужен в служебном чате (закрытая группа ведущих). После добавления можно вернуть Disable — в чаты сообщества бот не добавляется, посты рассылаются через inline-режим |
| `/setprivacy` | Enabled (по умолчанию): в группах боту не нужно читать сообщения |
| `/setcommands` | Не обязательно: команды задаются из кода через `setMyCommands` |

Права на боевого бота: владелец аккаунта в BotFather — один из владельцев проекта. При необходимости бота можно передать другому аккаунту через `/mybots` → Transfer ownership. При утечке токена — `/revoke`, новый токен в `.env` на сервере, перезапуск.

### Приложение Б. Пример жизненного цикла недели

Настройки по умолчанию: встреча в пятницу 16:30–18:30, автосоздание на следующий день после встречи в 10:00, напоминание о рассылке поста за 2 дня в 10:00, дедлайн отмены накануне в 20:00, закрытие записи через 60 минут после начала, запрос явки через 90 минут.

```mermaid
sequenceDiagram
    autonumber
    participant S as Планировщик
    participant B as Бот
    participant A as Админ
    participant C as Чаты
    participant U as Участник

    S->>B: Сб 10:00 — создать встречу на пятницу
    B->>A: «Создана встреча: пятница, …, 16:30. Разошлите пост…» (служебный чат)
    S->>B: Ср 10:00 — у встречи нет постов
    B->>A: «Пост встречи … ещё не разослан…» (служебный чат)
    A->>C: @имябота → выбрать встречу (в 2–3 чата)
    C-->>B: chosen_inline_result ×N (inline_message_id)
    U->>B: «Записаться»
    B-->>U: всплывающее окно: «Вы записаны на встречу: пятница, …, 16:30–18:30…»
    B->>C: правка всех постов: «Записались: 1 из 10»
    Note over B: … набралось 10 …
    U->>B: «Записаться» (11-й)
    B-->>U: «Мест нет, вы в листе ожидания под номером 1…»
    B->>C: правка постов: «В очереди: 1»
    S->>B: Чт 16:30 — напоминания
    B->>U: личка: «Напоминаем о встрече: пятница, …, 16:30–18:30, место…»
    Note over B: Чт 20:00 — дедлайн отмены (задачи нет: проверяется при нажатии «Отменить запись»)
    Note over B: Пт 16:30 — начало; запись открыта для опоздавших
    S->>B: Пт 17:30 — закрыть запись
    B->>C: посты без кнопок, «Запись закрыта»
    B->>A: «Запись на встречу (…) закрыта. Заполнено 10 из 10.» и список (служебный чат)
    S->>B: Пт 18:00 — запрос явки
    B->>A: список с переключателями
    A->>B: отметил неявку, «Готово»
    B->>B: правило бана → бан (по умолчанию после первой неявки)
    Note over B: Сб 10:00 — автосоздание следующей встречи
```

### Приложение В. Формат CSV-выгрузки

```csv
event_date,position,name,username,user_id,profile_link,status,guests,registered_at,attendance
2026-10-31,1,Света,sveta_mvd,111111,tg://user?id=111111,active,0,2026-10-26 10:03,attended
2026-10-31,2,Иван Петров (вручную),,,,active,0,2026-10-27 18:20,unknown
```

Кодировка UTF-8 с BOM, чтобы Excel правильно открывал кириллицу. Время в часовом поясе из настроек.

# 12. Интерфейс админа

### 12.1 Команды

Регистрируются через `setMyCommands`: `/start` и `/help` — для всех личных чатов (`BotCommandScopeAllPrivateChats`), `/menu` и `/cancel` — отдельно для каждого админа (`BotCommandScopeChat`). Список обновляется при запуске бота, при `/start` админа и при смене прав.

| Команда | Кто | Действие |
|---|---|---|
| `/start` | все | Приветствие и `dm_available = true`; админу добавлена подсказка про `@имябота` и `/menu`. Deep-link параметры: `remind` (включает напоминания и показывает записи человека), `about` (описание бота) |
| `/menu` | админы | Главное меню |
| `/help` | все | Как пользоваться (разный текст для участников и админов) |
| `/cancel` | админы | Выйти из текущего диалога |
| `/dev_shift <минуты>` | админы, только `ENV=dev` | Сдвинуть виртуальные часы (15.4). В боевом режиме молчит и в списке команд не показывается |

Любое другое сообщение в личке получает «Не понял. Помощь — /help» (админу — с подсказкой про `/menu`). Диалоги меню принимают ввод раньше этого ответа.

### 12.2 Дерево меню (aiogram-dialog)

```
Главное меню
├── 📅 Встречи
│   ├── [список открытых и за последние 14 дней: дата · статус · занято N из M]
│   │   └── Карточка встречи (время, место, статус, занято и очередь, моменты)
│   │       ├── 👥 Участники (список с номерами, ⏳ у очереди, 📵 у тех, кому не дойдут сообщения)
│   │       │   ├── ➕ Добавить участника (Выбрать пользователя Telegram / Ввести имя вручную;
│   │       │   │      при нехватке мест — «Добавить сверх лимита»)
│   │       │   └── [участник] → Удалить из встречи / Отменить без штрафа / Отменить как неявку /
│   │       │          🚫 Забанить (две средние кнопки — только после дедлайна отмены)
│   │       ├── ✏️ Редактировать: Описание, Фото, Место, Ссылка на место, Дата и время, Лимит мест,
│   │       │      Моменты (окончание, отмена, закрытие, напоминание, явка)
│   │       ├── 👁 Предпросмотр
│   │       ├── 🔒 Закрыть запись / 🔓 Открыть запись
│   │       ├── ✅ Отметить явку (только у завершённой встречи, до 7 суток после начала)
│   │       ├── 📤 Выгрузить CSV
│   │       └── ❌ Отменить встречу (причина → подтверждение)
│   ├── ➕ Новая встреча (мастер: дата с календарём и кнопкой «Ближайшая» → время → место →
│   │      текст объявления → фото → лимит мест → предпросмотр → ✅ Создать)
│   └── 🔄 Обновить
├── 🚫 Чёрный список
│   ├── [забаненный] → ✅ Разбанить / 📜 История
│   └── ➕ Забанить (выбрать пользователя + причина)
├── ⚙️ Настройки
│   ├── Встречи по умолчанию (лимит, день, время, длительность, место, ссылка на карту, описание, фото)
│   ├── Расписание (автосоздание, дедлайн отмены, закрытие записи, напоминания, запрос явки,
│   │      напоминание о рассылке поста)
│   ├── Правила (порог бана, снимать с будущих встреч, сообщать о бане, имена в посте, +1,
│   │      лист ожидания, порог «поздней» подвижки, уведомления админам)
│   ├── Тексты сообщений (19 текстов, «↩️ Сбросить по умолчанию»)
│   └── Часовой пояс
├── 👑 Админы (только владелец): список / ➕ Добавить админа / 🗑 Удалить из админов
└── ℹ️ Как разослать пост: инструкция про @имябота
```

Мастер подставляет значения прошлой неотменённой встречи (а если встреч не было — настроек по умолчанию) и предупреждает, если описание не помещается в подпись поста с фото. Календарь русский. Общие кнопки: «⬅️ Назад», «✖️ Отмена», «⬅️ К встрече», «⬅️ К списку», «⬅️ В меню».

Каждое разрушительное действие требует подтверждения: отмена встречи (после ввода причины), удаление участника и отмена его записи, уменьшение лимита, разбан, удаление админа; бан делается через ввод причины (или «Без причины»). Права проверяются на каждом действии, а не только при показе кнопки.

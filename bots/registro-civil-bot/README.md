# registro-civil-bot (rcbot)

Круглосуточно следит за календарём записи в Registro Civil (Уругвай, `bpmgob.mec.gub.uy`) и
мгновенно сообщает владельцу о свободных датах: в Telegram, push через ntfy и звонком через
CallMeBot. Записывается владелец сам — бот только читает календарь.

Полное ТЗ — [SPEC.md](SPEC.md). План и прогресс — [docs/ROADMAP.md](docs/ROADMAP.md).
Что нельзя ломать — [docs/architecture/invariants.md](docs/architecture/invariants.md).
Как устроен код — [docs/architecture/overview.md](docs/architecture/overview.md).

> **Состояние:** код написан (этап 1) и проверен тестами на синтетических данных (этап 2); на
> живом сайте и в реальном Telegram ещё не запускался. Дальше: подключение (этап 3), аудит
> (этап 4), работа (этап 5) — [ROADMAP](docs/ROADMAP.md).

## Платформа

Один ноутбук с Windows 11, Python 3.14, `uv`. Бот — часть монорепозитория: всё, что к нему
относится, лежит в этом каталоге (`data/`, `logs/`, `.browsers/`, `.cache/` в git не попадают).
Вне каталога — только секреты в Windows Credential Manager, задание Планировщика и журнал
наблюдения `rcbot-journal` на рабочем столе (решение R6, см. ниже).

Переменная окружения `RCBOT_HOME` (необязательная) переназначает каталог бота: оттуда берутся
`.env`, `alembic.ini`, `data/`, `logs/`, `.browsers/`, `.cache/`. Без неё — каталог
`bots/registro-civil-bot/`. Нужна тестам и особым случаям; в обычной работе её не задают.

## Быстрый старт (Windows 11)

Нужен только Windows 11 с интернетом; Python и зависимости поставит `uv`.

1. Скачайте репозиторий (`git clone` или архив с GitHub) и распакуйте в любую папку.
2. Откройте папку `bots\registro-civil-bot\scripts` и дважды щёлкните **`quickstart.cmd`**
   (или в PowerShell из корня: `bots\registro-civil-bot\scripts\quickstart.cmd`). Скрипт:
   - проверит `uv` и предложит поставить его через `winget`;
   - поставит зависимости (несколько минут, один раз);
   - найдёт Google Chrome или Microsoft Edge; если ни того ни другого нет, предложит скачать
     встроенный Chromium (около 740 МБ);
   - запустит мастер `rcbot init`: спросит номер этапа и номер заявки (из адресной строки и
     списка «Bandeja de entrada» на bpmgob), а секреты (номер документа, пароль gub.uy, токен
     Telegram-бота, @username для звонков) примет скрытым вводом и положит в Диспетчер
     учётных данных Windows. Тему ntfy создаст сам и покажет;
   - проверит окружение (`rcbot doctor`) и предложит включить автозапуск при входе в Windows.
3. Дальше команды запускаются коротко, из любой папки: `scripts\rcbot.cmd <команда>`.

```text
rcbot.cmd doctor          полная проверка окружения и доступа к сайтам
rcbot.cmd login --check   вход на сайт (пароль берётся из Диспетчера учётных данных)
rcbot.cmd check --once    одна проверка календаря
rcbot.cmd simulate        тестовая тревога во все каналы
rcbot.cmd run             работа в этом окне; постоянная — через автозапуск
```

Скрипту можно передать `-SkipInit` (пропустить мастер) и `-SkipAutostart` (не спрашивать про
автозапуск). Повторный запуск безопасен: сделанное раньше не затирается. Скрипт сам **не**
входит на сайт и не запускает разведку: это делаете вы командами выше. Что нужно сделать
самому до начала (бот в @BotFather, приложение ntfy, @CallMeBot) — в конце этого файла.

## Подготовка окружения для разработки

Из **корня** монорепозитория:

```powershell
uv run python dev.py setup --bot registro-civil-bot   # зависимости, .env, Chromium в .browsers/
uv run --all-packages rcbot init                      # .env, номер этапа и заявки, секреты, тема ntfy, chat_id
uv run --all-packages rcbot doctor                    # проверка всего
```

## Браузер

Бот работает в любом браузере на движке Chromium. По умолчанию (`RCBOT_BROWSER=auto`) он берёт
установленный **Google Chrome**, если его нет — **Microsoft Edge**, если нет и его — встроенный
Chromium Playwright (его ставит `dev.py setup`, около 740 МБ). Если у вас есть Chrome или Edge,
встроенный Chromium не нужен. Закрепить один браузер: `RCBOT_BROWSER=chrome`, `msedge` или
`chromium` — тогда запасных вариантов нет, и без выбранного браузера бот не запустится. Что
найдено и что будет использовано, показывает `rcbot doctor`; какой браузер реально запущен,
видно в журнале (строка «браузер: …»). Профиль, расширения и cookies вашего Chrome бот не трогает:
каждый раз открывается чистый временный контекст.

`setup` создаёт `bots/registro-civil-bot/.env` из `.env.example`. В `.env` — только несекретные
настройки: номер этапа в `RCBOT_AGENDA_URL` и номер заявки в `RCBOT_TRAMITE_ID`. Секреты
(номер документа, пароль gub.uy, токен Telegram, тема ntfy, @username для звонков) в файлы не
пишутся: их спрашивает `rcbot init` и кладёт в Windows Credential Manager.

## Команды

Все — из корня репозитория через `uv run --all-packages rcbot <команда>`:

| Команда | Что делает |
|---|---|
| `init` | Мастер: создаёт `.env` из `.env.example`, если его нет; спрашивает номер этапа (можно весь адрес шага «Agenda») и номер заявки и пишет их в `.env`; секреты в Credential Manager, тема ntfy, определение вашего chat_id |
| `doctor [--offline] [--full]` | Версии, браузеры (Chrome, Edge, Chromium), секреты, настройки, OneDrive, доступ к хостам, часы; `--full` — ещё `pip-audit` |
| `discover` | Разведка: окно браузера, вы входите сами, бот записывает очищенные запросы календаря |
| `login [--check]` | Вход на сайт; `--check` — пускает ли сайт сразу на шаг «Agenda» |
| `check --once` | Одна проверка календаря |
| `run` | Постоянная работа (для отладки в консоли; в обычной жизни — через Планировщик) |
| `simulate [--wait 600]` | Тестовая тревога во все каналы с повторами до «Вижу» |
| `purge` | Удалить логи, временные файлы, карантин, снимки, дампы, кеш (база, `.env` и Chromium остаются) |
| `uninstall` | Удалить секреты из Credential Manager и задание Планировщика |

Ни `purge`, ни `uninstall` не трогают журнал наблюдения: папку `rcbot-journal` на рабочем столе
(или `RCBOT_JOURNAL_DIR`) после удаления бота удалите вручную.

Автозапуск: `powershell -ExecutionPolicy Bypass -File bots\registro-civil-bot\scripts\register_task.ps1`
(при входе в Windows, без окна, перезапуск при сбое). В настройках питания от сети: «Переводить
в спящий режим» — «Никогда», закрытие крышки — «Ничего не делать».

## Журнал наблюдения на рабочем столе

Папка `rcbot-journal` на рабочем столе (путь меняется настройкой `RCBOT_JOURNAL_DIR`). Её можно
смотреть в любой момент, даже когда мест нет:

| Что | Где |
|---|---|
| Текущее состояние, «жив / завис» | `status.json` — `alive_at` обновляется каждые 30 с; если он старше нескольких минут, бот не работает |
| Каждая проверка календаря | `checks/checks-ГГГГ-ММ-ДД.jsonl` — время, источник, найденные даты или ошибка, время ответа |
| Каждое действие и событие | `events/events-ГГГГ-ММ-ДД.jsonl` — входы, смены состояния, тревоги, доставки, «Вижу», команды, зависания, очистки |
| Подробный лог | `logs/rcbot-ГГГГ-ММ-ДД.log` |
| Когда открывались окна записи | `openings.csv` — открывается в Excel |

Если папка больше `RCBOT_JOURNAL_MAX_GB` (10 ГБ), бот сам удаляет самые старые дни, пока не
останется `RCBOT_JOURNAL_TRIM_TO_GB` (5 ГБ); сегодняшние файлы и статистика окон не удаляются.
Секретов, cookies, номера документа и номеров заявки в журнале нет.

Если проверка зависнет дольше 150 секунд, она прерывается; если встанет весь цикл опроса, бот
сам перезапустит его вместе с браузером и напишет об этом в Telegram.

Запись журнала идёт в фоновом потоке (`RCBOT_JOURNAL_BACKGROUND`, по умолчанию включено): проверка
не ждёт диска. `false` — запись в том же потоке, нужно только отладке и тестам.

## Тесты

```powershell
uv run python dev.py test --bot registro-civil-bot          # весь набор и порог покрытия 85 %
uv run python dev.py quality-gate --bot registro-civil-bot  # плюс ruff, mypy, раскладка
```

Тесты идут без сети и без настоящих данных; устройство набора — `docs/testing.md`. Тесты с
Chromium требуют `uv run python dev.py setup --bot registro-civil-bot`, иначе пропускаются.

## Управление из Telegram

`/help` (и `/start`) — список команд; `/status`, `/pause [минуты]`, `/resume`, `/interval <сек>`
(не меньше 10), `/test`, `/last`, `/relogin`, `/cleanup`, `/menu`. Тревога подтверждается кнопкой «✅ Вижу» или словом «ок».
Если сайт потребует шаг 1 с контрольным вопросом, бот попросит пройти его в вашем браузере и
нажать «Готово» — сам он на вопрос не отвечает.

## Что владелец делает сам (SPEC.md, 9.1)

1. Создать бота у @BotFather и написать ему `/start`.
2. Поставить на телефон приложение ntfy.
3. Написать `/start` боту @CallMeBot_txtbot и разрешить звонки.
4. Когда попросит ассистент: ввести секреты в `rcbot init`, один раз войти в gub.uy в окне
   `rcbot discover`, подписаться на тему ntfy, ответить на тестовый звонок.

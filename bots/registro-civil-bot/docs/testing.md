# Тесты registro-civil-bot

Этап 2 плана (`ROADMAP.md`, решение R5): бот проверяется на синтетических данных, **без** живого
сайта, реальных токенов, Telegram, ntfy и CallMeBot (SPEC 6.4). Требования к тестам — SPEC 7
(уровни: юнит, интеграция, скорость, приватность) и 3.4 (покрытие `domain` и `application` ≥ 85 %).
Решение по инструментам — R7 в `open-questions.md`.

## Запуск

Из корня монорепозитория:

```powershell
uv run python dev.py test --bot registro-civil-bot                    # полный прогон + порог покрытия
uv run python dev.py test --bot registro-civil-bot tests/unit/domain  # часть (покрытие не считается)
uv run python dev.py quality-gate --bot registro-civil-bot            # ruff, mypy, раскладка, тесты
```

Полный прогон без своих аргументов добавляет `--cov` для `rcbot.domain` и `rcbot.application` и
падает при покрытии ниже порога из `[tool.monorepo]` в `pyproject.toml` бота.

## Раскладка

| Каталог | Что проверяет |
|---|---|
| `tests/unit/` | Одна единица за раз: домен, настройки, логика цикла опроса, рассылки, разбор страниц, каналы |
| `tests/integration/` | Несколько частей вместе: настоящая SQLite, миграции, настоящий Chromium на локальных страницах, настоящие сокеты и TLS к локальному серверу |
| `tests/e2e/` | Сквозные сценарии SPEC 7: «нет мест → есть → пропали», 302, 429, 503, неожиданный формат → карантин → `DomSource`, скорость < 100 мс |
| `tests/privacy/` | Секреты, cookies и номера не попадают в логи, БД, журнал, фикстуры, внешние каналы |
| `tests/architecture/` | Границы слоёв, инварианты SPEC 0.3 (только чтение, минимум 10 с) |
| `tests/fakes.py`, `tests/conftest.py` | Общие фейки и фикстуры — меняет только тимлид |

## Общие инструменты

- **Часы.** `FakeClock` — время бежит само; `ManualClock` — время идёт по `await clock.advance(n)`,
  спящие задачи просыпаются по порядку сроков (повторы, паузы, расписание проверяются по точным
  моментам). `datetime.now()` и реальный `sleep` в тестах не используются.
- **Адаптеры.** `FakeSource`, `FakeAuthenticator`, `FakeNotifier`, `Memory*` (хранение в памяти),
  `RecordingJournal`.
- **Сеть.** `LocalTlsServer` — настоящий HTTPS-сервер на 127.0.0.1 с сертификатом `trustme`;
  `SafeHttp(..., ssl_context=server.client_ssl)` ходит к нему по реальным сокетам. Проверка TLS
  в работе не отключается: без доверия к тестовому центру сертификации запрос отклоняется.
- **Браузер.** Тесты с маркером `@pytest.mark.browser` запускают настоящий Chromium из `.browsers/`
  на локальных страницах (`file://`, локальный сервер, `page.route`); без Chromium пропускаются.
- **Свойства.** `hypothesis` для детектора, разбора календаря, редактора секретов, расписания.
- **Изоляция** (автоматически для каждого теста): `RCBOT_*` из окружения удалены, `RCBOT_HOME` и
  журнал — во временных папках, keyring — в памяти (Credential Manager не затрагивается), фильтр
  секретов и логгер возвращаются в исходное состояние.

## Правила

- Тест проверяет поведение и условия SPEC, а не пересказывает код. Тест, который проходит при
  сломанном коде, бесполезен: проверяйте ожидание, которое сломанный код нарушит.
- Не ослаблять, не отключать и не удалять тесты, чтобы позеленить сборку; нашли ошибку в коде —
  исправляйте код (с регрессионным тестом).
- Данные синтетические. Настоящих номеров заявки и этапа, паролей и токенов в тестах нет.
- Ни тесты, ни разработчик не обращаются к `bpmgob.mec.gub.uy`, `mi.iduruguay.gub.uy` и другим
  настоящим адресам; запросы идут к локальным серверам.

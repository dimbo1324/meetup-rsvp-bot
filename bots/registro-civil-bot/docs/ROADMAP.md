## 2. Фазы подробно

### P−1. Подготовка репозитория

**Статус.** Готово 2026-11-11. Поставлено: каталог `bots/registro-civil-bot/` в монорепозитории
(контракт — `docs/monorepo.md` корня), зависимости из SPEC.md 2.1 в общем `uv.lock`, пакет `rcbot`
(только `__init__.py`), Chromium для Playwright в `.browsers/` (команда `dev.py setup`),
`SPEC.md` без номеров заявки (решение R1), правила бота для ассистентов (`CLAUDE.md`,
`.ai/`, агенты `rcbot-*`), дымовой тест стека `tests/test_stack.py`. Проверено: Playwright
1.65 и greenlet ставятся на Python 3.14 под Windows из готовых колёс, поэтому запасной путь D7
(отдельное окружение на 3.13) не нужен. Все версии в `uv.lock` совпадают с таблицей SPEC 2.1.
Кода фаз P0–P8 нет. Найдено при проверке и вынесено владельцу: aioresponses несовместима с
aiohttp 3.14 (Q-M3, решить до P3), браузеры занимают 741 МБ против критерия 8 «папка < 300 МБ»
(Q-M2, решить до P0).

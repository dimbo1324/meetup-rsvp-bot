# Правила бота registro-civil-bot (rcbot)

Источник требований — `bots/registro-civil-bot/SPEC.md`. При расхождении кода и SPEC.md —
спросить владельца, а не выбирать самому.

## Жёсткие границы (SPEC.md 0.3; `docs/architecture/invariants.md`)

- Бот **только читает** календарь. Запрещён код, который выбирает дату, нажимает
  «Siguiente» или «Guardar y Cerrar», платит или решает контрольный вопрос шага 1. Решатель
  вопроса из прототипа `registro_bot.zip` не переносится.
- Минимальный интервал опроса 10 с зашит в коде и не настраивается ни `.env`, ни Telegram;
  `DomSource` — не чаще раза в 60 с. На 403/429/5xx — экспоненциальная пауза, не повтор в лоб.
- Только аккаунт владельца, один IP, без прокси и подмены отпечатка браузера.

## Приватность и секреты

- Секреты — только через keyring (Windows Credential Manager, служба `rcbot`). В `.env` —
  только несекретное.
- Секреты, cookies, номер документа, имя, почта, телефон не пишутся в логи, БД, тесты,
  фикстуры, коммиты и внешние каналы. Номер заявки и этапа — только в локальном `.env`
  (решение R1): в коде, тестах и документах — метки `<НОМЕР_ЗАЯВКИ>`, `<НОМЕР_ЭТАПА>`.
- Сеть — только по списку разрешённых хостов SPEC.md 2.6, TLS всегда проверяется.
- Тесты **не обращаются к живому сайту**: только фикстуры и фальшивый сервер aiohttp.
  Ассистент сам на bpmgob.mec.gub.uy и mi.iduruguay.gub.uy не ходит; разведку (`rcbot discover`)
  запускает на ноутбуке владельца по его просьбе, вход выполняет владелец.

## Код

- Слои SPEC.md 2.3: `domain` без внешних зависимостей (не импортирует aiohttp, aiogram,
  sqlalchemy, playwright); зависимости — через конструкторы, без глобальных синглтонов; время —
  только через порт `Clock`. Каждая граница слоёв получает тест импорта.
- `mypy --strict` для всего `src/rcbot`, ruff, покрытие `domain` и `application` ≥ 85 %.
- Все сетевые вызовы с таймаутом; голых `except:` нет; завершение по Ctrl+C закрывает
  соединения и браузер по порядку.
- На Windows — стандартный `ProactorEventLoop` без смены политики; uvloop — только на Linux.
- Пути — от каталога бота (R2); `data/`, `logs/`, `.browsers/`, `.cache/` в git не идут.
  Журнал наблюдения — на рабочем столе (R6): тоже без секретов, через тот же фильтр.

## Процесс

- Работаем **по этапам владельца** (решение R5; `docs/ROADMAP.md`, §1): бизнес-логика → тесты →
  подключение → аудит → работа. Внутри этапа фазы SPEC по порядку, коммит на фазу; в конце
  этапа — статус в ROADMAP, демонстрация владельцу и **остановка** до его ответа.
- Перед коммитом: `uv run python dev.py quality-gate --bot registro-civil-bot` (решение R4).
- Специалисты: `rcbot-core`, `rcbot-integrations`, `rcbot-privacy` (зоны — в их описаниях).

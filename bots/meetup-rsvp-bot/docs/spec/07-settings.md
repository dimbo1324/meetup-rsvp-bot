# 7. Настройки

Хранятся в таблице `settings` (ключ → JSON-значение). Схема (ключ, тип, умолчание, ограничения) — `src/meetup_bot/services/settings_schema.py`; значения по умолчанию — `services/defaults.py` и (для текстов) `texts/defaults.py`. В БД лежат только изменённые значения. Любое изменение пишется в `audit_log`.

| Ключ | Тип | По умолчанию | Ограничения | Описание |
|---|---|---|---|---|
| `capacity` | int | 10 | 1–200 | Лимит мест для новых встреч |
| `event_weekday` | int | 4 (пт) | 0–6, пн = 0 | День встречи. Остальные дни расписания считаются от него («день до», «день после»), а не от дней недели |
| `event_time` | HH:MM | 16:30 | формат ЧЧ:ММ | Время начала |
| `event_duration_minutes` | int | 120 | 15–720 | Длительность встречи; в посте показывается интервал «16:30–18:30» |
| `default_place` | str | «» | ≤ 200 | Место по умолчанию |
| `default_place_url` | url | «» | `https://`, ≤ 2000, без пробелов и символов `" ' < > \` | Ссылка на карту |
| `default_description` | html | «» | теги Telegram, ≤ 3500; свыше 700 — предупреждение (5.10) | Текст поста по умолчанию |
| `default_photo_file_id` | str | null | ≤ 256, без пробелов | Фото по умолчанию (`file_id`) |
| `auto_create_enabled` | bool | true | — | Автосоздание встреч |
| `auto_create_days_after` | int | 1 | 0–6 | Через сколько дней после встречи создавать следующую («день после») |
| `auto_create_time` | HH:MM | 10:00 | формат ЧЧ:ММ | Во сколько создавать |
| `cancel_deadline_days_before` | int | 1 | 0–7 | Дедлайн отмены: за сколько дней |
| `cancel_deadline_time` | HH:MM | 20:00 | формат ЧЧ:ММ | Дедлайн отмены: во сколько |
| `registration_close_minutes_after_start` | int | 60 | 0–240 | Закрытие записи через N минут после начала: опоздавшие могут записаться, пока есть места. 0 — в момент начала. Админ закрывает вручную в любой момент |
| `reminder_enabled` | bool | true | — | Напоминания в личку |
| `reminder_hours_before` | int | 24 | 1–72 | Когда напоминать |
| `attendance_prompt_minutes_after` | int | 90 | 30–2880 | Когда просить админов отметить явку (минут после начала); не раньше закрытия записи |
| `post_reminder_days_before` | int | 2 | 0–14 | За сколько дней до встречи напомнить в служебном чате, что пост не разослан; 0 — выключено |
| `post_reminder_time` | HH:MM | 10:00 | формат ЧЧ:ММ | Во сколько напоминать о рассылке поста |
| `ban_after_no_shows` | int | 1 | 0–10 | Порог бана, 0 = автобан выключен |
| `remove_banned_from_future_events` | bool | true | — | Снимать забаненного с будущих встреч |
| `notify_user_on_ban` | bool | false | — | Сообщать человеку о бане |
| `show_names_in_post` | bool | false | — | Имена в посте или только счётчик и очередь. Админы видят имена в своих списках всегда |
| `plus_one_enabled` | bool | false | — | Кнопка «+1» |
| `waitlist_enabled` | bool | true | — | Лист ожидания |
| `late_promotion_hours` | int | 24 | 0–72 | См. 5.5 |
| `notify_admins_on_full` | bool | true | — | Уведомлять о заполнении |
| `notify_admins_on_cancel` | bool | true | — | Уведомлять об отменах |
| `timezone` | IANA | America/Montevideo | валидный `zoneinfo` | Часовой пояс |
| `text.*` | str | раздел 6 | всплывающие окна ≤ 200 символов (по худшему случаю подстановок), сообщения — шаблон ≤ 3500; только известные подстановки | 19 текстов |

**Что действует на уже созданные встречи.** Моменты встречи (длительность, дедлайн отмены, закрытие записи,
напоминание, запрос явки — 5.2) вычисляются при её создании и сохраняются в ней: новые значения получают только
**новые** встречи, а у созданной моменты меняются в её карточке («Моменты»). Остальное читается в момент действия
и работает сразу: правила (порог бана, `show_names_in_post`, `plus_one_enabled`, `waitlist_enabled`,
`late_promotion_hours`, уведомления админам, `reminder_enabled`), автосоздание, напоминание о рассылке поста,
часовой пояс и тексты. Умолчания встречи (`capacity`, `default_*`) подставляются только в новые встречи.

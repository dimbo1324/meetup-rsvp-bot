# 16. Тестирование и качество кода

### 16.1 Подход

- Основная масса тестов — на **сервисы**, с настоящей файловой SQLite (она проверяет блокировки и `BEGIN IMMEDIATE`, как в бою) и `FakeClock`. Сервисы тестируются без Telegram: порты `Notifier` и `PostRefresher` записывающие (`tests/helpers.py`).
- Telegram-слой и диалоги тестируются через **строгий фейк Telegram** (`tests/tg_fake.py`): фейковая сессия бота отвечает как Bot API и отклоняет нарушения лимитов (текст 4096 по видимой длине в UTF-16, подпись 1024, `callback_data` 64 байта, ответ на callback 200 символов), а `Harness` поднимает настоящие роутеры и диалоги.
- Рендер поста тестируется отдельно: длина, экранирование, все статусы, интервал.
- Архитектурные тесты (`tests/test_architecture.py`) стерегут слои, время только через `Clock`, единственность определений, отсутствие текстов в сервисах и записи в БД из диалогов и обработчиков.
- Всего 2261 тест (на Windows 3 пропускаются — проверки POSIX-прав файлов бэкапа). Реальный Telegram тестами не охвачен: ручной проход — `docs/telegram-test-checklist.md`.
- Покрытие сервисов не ниже 85%.

### 16.3 Инструменты

- `ruff check` + `ruff format` (pre-commit и CI).
- `mypy` в строгом режиме для `services/`, `repositories/`, `renderer/`, `telegram/`, `db/`, `clock` и `config`; в остальных модулях (`dialogs/`, `handlers/`, `scheduler/`, `texts/`, `app`, `container`) — мягче (`check_untyped_defs`). Тесты mypy не проверяет.
- Команды через `dev.py`: `format`, `lint`, `typecheck`, `test`, полный шлюз `quality-gate` (синхронизация правил, паритет зеркал, lint, typecheck, test).
- Правило: никаких naive datetime (`ruff DTZ`). Время только через `Clock`.

### 16.4 Definition of Done для задачи

- Код попадает в `main` fast-forward слиянием после зелёного `quality-gate`; CI зелёный.
- Бизнес-логика покрыта тестами, новые сценарии добавлены в 16.2.
- Изменения в БД — через миграцию Alembic.
- Новые тексты и настройки добавлены в разделы 6 и 7 этого документа.
- Для значимых изменений интерфейса — проверено руками в тестовой группе (`docs/telegram-test-checklist.md`).

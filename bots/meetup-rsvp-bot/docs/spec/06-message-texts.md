# 6. Тексты сообщений

Все тексты участникам хранятся в настройках (`text.*`) и меняются админом; значения по умолчанию лежат в
`src/meetup_bot/texts/defaults.py`. В БД записываются только изменённые тексты.

**Подстановки:** `{weekday}`, `{date}`, `{time}` (начало), `{end_time}` (конец встречи), `{deadline}` (дедлайн
отмены, например «30 октября, 20:00»), `{place}`, `{position}` (место в очереди), `{name}`, `{reason}`.
Значение `{reason}` уже содержит префикс «Причина: » и пусто, если причины нет; пустые подстановки не оставляют
«висящих» запятых и пробелов. При сохранении бот пробует отрендерить текст тестовыми значениями и отклоняет его
при неизвестной подстановке или некорректных фигурных скобках.

**Два вида текстов:**

- *Всплывающие окна* — ответ на нажатие кнопки (`show_alert`). Лимит Telegram — **200 символов**; бот проверяет
  его при сохранении по худшему случаю (самое длинное место, имя, причина).
- *Сообщения* (`text.reminder`, `text.promoted`, `text.event_cancelled`, `text.event_moved`,
  `text.attendance_marked_by`, `text.ban_notice`) уходят обычным сообщением в `parse_mode=HTML`: лимита 200 нет,
  шаблон до 3500 символов (и не больше 4096 с самыми длинными подстановками), подставляемые значения
  экранируются.

| Ключ | Когда | Текст по умолчанию |
|---|---|---|
| `text.registered` | Успешная запись | Вы записаны на встречу: {weekday}, {date}, {time}–{end_time}. Если планы изменятся, отмените запись до {deadline}. |
| `text.registered_late` | Запись после дедлайна отмены | Вы записаны на встречу: {weekday}, {date}, {time}–{end_time}. Обратите внимание: отменить запись уже нельзя. |
| `text.full` | Мест нет | Извините, мест не осталось. Попробуйте в следующий раз! |
| `text.waitlisted` | Встал в лист ожидания | Мест нет, вы в листе ожидания под номером {position}. Если место освободится, бот напишет вам. |
| `text.already` | Повторное нажатие «Записаться» | Вы уже записаны. |
| `text.already_waitlist` | Повторное нажатие в листе ожидания | Вы уже в листе ожидания, номер {position}. |
| `text.only_one_seat` | «+1» при одном свободном месте | Осталось одно место — запишитесь без гостя. |
| `text.closed` | Запись закрыта | Запись на эту встречу закрыта. |
| `text.banned` | Человек в бане | К сожалению, вы не можете записываться на встречи. Если это ошибка, напишите администратору. |
| `text.cancelled` | Успешная отмена | Запись отменена. Спасибо, что предупредили! |
| `text.cancel_too_late` | Отмена после дедлайна | Отменить запись уже нельзя. Если не можете прийти, напишите администратору. |
| `text.not_registered` | Отмена без записи | Вы не были записаны на эту встречу. |
| `text.enable_dm_hint` | Подсказка, если у бота нет личного чата с человеком | Нажмите «Старт» у бота, чтобы получать напоминания. |
| `text.reminder` | Напоминание в личку (сообщение) | Напоминаем о встрече: {weekday}, {date}, {time}–{end_time}, {place}. Не сможете прийти? Отмените запись до {deadline}. |
| `text.promoted` | Продвижение из листа ожидания (сообщение) | Освободилось место — вы записаны на встречу: {weekday}, {date}, {time}–{end_time}! |
| `text.event_cancelled` | Встреча отменена (сообщение) | Встреча {date} отменена. {reason} |
| `text.event_moved` | Сообщение о переносе встречи (сообщение) | Встреча перенесена: теперь {weekday}, {date}, {time}–{end_time}, {place}. |
| `text.attendance_marked_by` | Подпись «явку отметил(а) …» (сообщение) | Явку отметил(а) {name} |
| `text.ban_notice` | Сообщение человеку о бане (если включено notify_user_on_ban) (сообщение) | Вы больше не можете записываться на встречи. Если это ошибка, напишите администратору. |

## Служебные сообщения

Сообщения бота админам не настраиваются из меню (`src/meetup_bot/texts/service.py`). Они уходят в служебный
чат, а при его недоступности — владельцам в личку.

| Когда | Текст |
|---|---|
| Автосоздание встречи | Создана встреча: {when}. Разошлите пост: в нужном чате наберите @ и имя бота и выберите встречу. |
| Встреча без поста (за `post_reminder_days_before` дней) | Пост встречи {when} ещё не разослан. Чтобы разослать: в нужном чате наберите @ и имя бота и выберите встречу. |
| Закрытие записи (первая строка, затем список) | Запись на встречу ({when}) закрыта. / Заполнено {taken} из {capacity}. |
| Последнее место занято | Встреча {when} заполнена: занято {taken} из {capacity}. |
| Участник отменил запись | {name} отменил(а) запись на встречу {when}. Занято {taken} из {capacity}. |
| Явку не отметили за 14 часов | Никто ещё не отметил явку на встрече ({when}). |
| Запуск бота | Бот запущен, версия {version} (в режиме `ENV=dev` с первой строкой «⚠️ РЕЖИМ DEV») |
| Резервная копия (подпись документа) | Резервная копия базы: {name} |
| Ошибка в обработчике | ⚠️ Ошибка: {kind} |
| Планировщик остановился | ⚠️ Планировщик остановился: {error} |
| Служебный чат недоступен (дубль владельцам) | ⚠️ Служебный чат недоступен, поэтому сообщение пришло вам лично. |
| Группа стала супергруппой | Группа стала супергруппой с новым id. Укажите SERVICE_CHAT_ID={chat_id} в .env и перезапустите бота. |
| Служебный чат публичный | ⚠️ Служебный чат публичный или не является группой: резервные копии базы с данными участников могут увидеть посторонние. Сделайте его закрытой группой. |
| Бот не видит служебный чат | ⚠️ Бот не видит служебный чат: проверьте SERVICE_CHAT_ID и что бот добавлен в чат. |

Здесь `{when}` — «пятница, 30 октября, 16:30» в часовом поясе из настроек.

## Тексты, зашитые в обработчики

Эти тексты лежат в коде (`handlers/`, `middlewares/`, `telegram/common.py`) и **не настраиваются из меню**:
чтобы их поменять, нужна правка кода. Подстановки `{name}`, `{bot}`, `{when}` и т. п. здесь — поля `str.format`.

| Где | Когда | Текст |
|---|---|---|
| `handlers/start.py`, `WELCOME_USER` | `/start` | Здравствуйте, {name}! Я помогаю записываться на встречи клуба.<br>Пост со встречей приходит в чат от администратора — нажмите «Записаться» под ним. Здесь, в личке, я буду присылать напоминания и сообщать, если освободится место. |
| `WELCOME_ADMIN_EXTRA` | `/start` у админа (дописывается) | Вы администратор. Чтобы разослать пост, наберите @{bot} в нужном чате и выберите встречу. Меню администратора — команда /menu. |
| `REMIND_ON` + список | `/start remind` (ссылка из окна записи) | Напоминания включены. Я напишу вам перед встречей и если освободится место. |
| `REMIND_REGISTRATIONS_HEAD`, `REMIND_LINE_ACTIVE`, `REMIND_LINE_WAITLIST` | `/start remind`, если есть записи | Ваши записи:<br>• {when}, {place} — вы записаны (с гостем — «(+1)»)<br>• {when}, {place} — вы в очереди, номер {position} |
| `REMIND_NO_REGISTRATIONS` | `/start remind`, записей нет | Записи на ближайшие встречи нет. Чтобы записаться, нажмите «Записаться» под постом. |
| `ABOUT_TEXT` | `/start about` (кнопка у не-админа в inline-режиме) | Я бот записи на встречи клуба. Пост со встречей приходит в чат, а запись и отмена делаются кнопками под ним. Напоминания включены: я напишу вам перед встречей. |
| `HELP_*` | `/help` | Как пользоваться ботом: под постом нажмите «Записаться» (при включённом «+1» — ещё «Записаться +1»), передумали — «Отменить запись» до указанного срока, `/start` включает напоминания; у админа дописаны подсказки про `@{bot}`, `/menu` и `/cancel` |
| `handlers/start.py`, dev | `/start` при `ENV=dev` | ID пользователя: <id> (дописывается) |
| `handlers/start.py`, `/dev_shift` | только `ENV=dev` и только админ | Часы сдвинуты на {minutes} мин. Сейчас: {now}. |
| `handlers/fallback.py` | Любое сообщение в личке, которое не поняли команды и диалоги | Не понял. Помощь — /help (админу: Не понял. Меню — /menu, помощь — /help) |
| `middlewares/rate_limit.py` | Больше 5 нажатий за 2 секунды | Слишком часто, подождите секунду. (сообщения в личке в этом случае игнорируются без ответа) |
| `handlers/signup.py` | Встреча не найдена | Встреча не найдена |
| `handlers/signup.py` | «+1» нажали, когда настройка уже выключена | Запись с гостем сейчас недоступна. |
| `handlers/signup.py` | Кнопка старого формата | Эта кнопка устарела. Откройте свежий пост встречи. |
| `handlers/errors.py` | Нажатие в окне меню после перезапуска бота | Это меню устарело. Откройте его заново командой /menu. |
| `telegram/common.py` | Внутренняя ошибка в обработчике | Что-то пошло не так, попробуйте ещё раз. |
| `telegram/errors_text.py` | Отказ сервиса в меню (коды `ErrorCode`) | «Нет доступа.», «Лимит не может быть ниже числа занятых мест. Сначала уберите лишних.» и др. — полный перечень в `ERROR_TEXTS` |

# meetup-rsvp-bot — правила бота для Claude Code

Claude Code загружает этот файл, когда работа касается каталога `bots/meetup-rsvp-bot/`.
Он **дополняет** корневой `CLAUDE.md` монорепозитория: общие правила действуют, правила бота
главнее там, где они строже. Codex читает те же правила через сгенерированный `AGENTS.md`
этого каталога (руками не править: меняйте модуль `.ai/`, затем `dev.py sync-agents`).

Telegram-бот записи на еженедельные встречи русскоязычного сообщества в Монтевидео:
ограниченное число мест, поимённая запись, бан за неявку, управление из Telegram. Продуктовое
намерение — `docs/spec/README.md` (индекс спецификации); план — `docs/ROADMAP.md`; реальное
состояние — `docs/architecture/overview.md`; инварианты — `docs/architecture/invariants.md`.
Тесты описывают требования: при расхождении меняется код, а не тест.

Специалисты: `meetup-core`, `meetup-telegram`, `meetup-security`.
